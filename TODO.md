# AI Research Assistant — delivery checklist

- [x] Serve a responsive, accessible public interface for uploading a PDF, summarizing it, and asking grounded questions.
- [x] Validate PDF type and size, extract selectable text in the browser, preserve page references, and explain OCR requirements for scanned files.
- [x] Chunk the current document and retrieve relevant passages with a lightweight no-cost in-browser method.
- [x] Generate concise and detailed summaries from extracted document content with transparent fallback messaging.
- [x] Answer document questions using retrieved evidence, show source document/page/excerpts, and refuse unsupported questions.
- [x] Maintain current-session history with clear reset controls and privacy guidance.
- [x] Provide in-product status, setup, low-cost, privacy, and limitation guidance for optional Ollama/Llama and ChromaDB enhancement.
- [x] Expose the route manifest, health check, build configuration, and a permanent published checkpoint.
